# GoChat

`GoCHAT` is a Discord-like chat application built in Go using TCP connections. It supports lobby-based communication, allowing multiple users to join chat rooms and exchange messages in real time.

This project is being developed as a systems-oriented networking application, with planned improvements including authentication, file transfer, a terminal user interface, and more secure communication.

## Features

- Built with Go
- Uses raw TCP connections for communication
- Supports lobby-wise / room-based chat
- Real-time multi-user messaging
- Lightweight and focused on networking fundamentals

## Planned Improvements

The following features are currently planned:

- Login / user authentication
- File transfer between users or within lobbies
- TUI (Terminal User Interface)
- Secure transfer protocol / encrypted communication

## Goals

This project is meant to explore and strengthen understanding of:

- TCP socket programming in Go
- Concurrent client handling
- Chat server architecture
- Room / lobby management
- Building networking tools with clean systems design

## Tech Stack

- Go
- TCP sockets

## Project Status

This project is currently under active development.

## Future Scope

In future versions, the application may evolve to include:

- Persistent user sessions
- Lobby moderation features
- Better message formatting
- Secure communication channels
- Improved client-side user experience through a TUI

## Motivation

This project was built to better understand low-level networking concepts and backend communication patterns by recreating the core ideas of a lobby-based chat system similar to Discord.

## Notes

This is a learning and systems-building project inspired by Discord-style communication, but it is not affiliated with or connected to Discord.
